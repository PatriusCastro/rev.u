From point A, the angle of elevation of the top of a tower is 30°. From B, 40 m closer, it is 60°. Find the height of the tower.
Start with the right triangle at B. Write h in terms of the distance from B to the tower.

Repeat schedule

1 day3 days7 daysCleared

Solution

  1. Let x be the distance from B to the tower.
  2. From B: tan 60° = h / x, so h = √3·x.
  3. From A: tan 30° = h / (x + 40), so x + 40 = 3x and x = 20 m.
  4. h = 20√3 ≈ 34.64 m

Today, reworked

  • The repeats card comes first. It is the one thing to do, so it sits above the statistics, not below them.
  • It says what the work is. The card shows how long the set should take and how old each repeat is, so a reviewer can decide to start before opening it.
  • One full-width button. Start repeats is the only filled control on the screen and is easy to reach with a thumb.
  • The rest of the route follows. Stops 2 and 3 sit directly under the card under a plain "Then".
  • Statistics move to the side. Progress, days to the exam and the week's chart sit below on a phone and in a second column on wider screens.

Scratch pad

A drawing surface for working a problem by hand, opened from the problem screen. It takes a finger, a stylus or a mouse, and has a pen, an eraser, undo and clear.

  • Phone: it slides up as a sheet over the lower part of the screen, leaving the problem visible above it.
  • Tablet and laptop: it sits beside the problem, so the reviewer reads on the left and writes on the right.
  • Full screen: a button in the pad's toolbar expands it to fill the whole app at any width. The problem text and its figure stay in a strip at the top, and the same button or the Escape key returns to the normal view. The working is kept when switching.
  • Version 1 does not save the working. It stays while the reviewer is on that problem and is cleared on the next one. Saving it to the mistake notebook is a later upgrade if reviewers ask for it.
